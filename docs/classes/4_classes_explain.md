## 二、分项算法速查+逐点校验细则（核心勘校主体）
### 模块1：积数与入局算法（积年/积月/积日/积时 → 太乙宫位）
#### 通用公式前缀
基础周期公数：360（大纪）、72（一元）、24（一气）、18（天目周），四派公数一致，**差异在使用规则**。

##### 1.1 年计入局
| 流派 | 计算步骤 | 校验要点 | 原文典型关键词 |
| ---- | ---- | ---- | ---- |
| 金镜派 | 1.积年 ÷ 360 取余<br>2.余数 ÷ 72 取余<br>3.余数 ÷ 24 取余<br>4.余数以三约之入九宫 | 全程一套规则，无阴阳区分、无十六神介入 | “积年去周纪、元法、气法，入九宫” |
| 福应经派 | 步骤完全同金镜；入局后绑定阴阳局 | 计算流程不变，结果附加阴阳属性 | “入局分阴阳，阳顺阴逆” |
| 统宗派 | 分层计算更细化，余数严格对应72局、24气、九宫；不入十六神 | 年计固守九宫体系，不与月/时计混同 | “岁计居九宫，不用十六神” |
| 淘金歌派 | 弃积年运算：甲子起1宫，逐年顺行一宫轮九宫 | 无除法运算，纯顺轮口诀 | “上元甲子起一宫，逐年顺行九宫通” |

##### 1.2 月计入局
| 流派 | 计算步骤 | 校验要点 | 原文典型关键词 |
| ---- | ---- | ---- | ---- |
| 金镜派 | 积月=积年×12+当月序，**直接套用年计入局模板** | 月计无独立周期，完全依附年计 | “月计同岁计，循九宫而行” |
| 福应经派 | 积月计算同金镜；余数再除18定阴阳局，入局顺逆随阴阳 | 框架沿用，新增阴阳判定环节 | “月纪一十八周，分阴阳二遁” |
| 统宗派 | 1.积月 ÷ 18（天目周）取余<br>2.自**武德/阴德**起顺行十六神定局 | **彻底脱离年计九宫，专属十六神体系** | “月计三十载一周，天目周十八，异于岁计” |
| 淘金歌派 | 正月起1宫，逐月顺行一宫，十二月循环 | 无积月计算，按月轮宫口诀 | “月起正月一宫行，次第轮流十二辰” |

##### 1.3 日计入局
| 流派 | 计算步骤 | 校验要点 | 原文典型关键词 |
| ---- | ---- | ---- | ---- |
| 金镜派 | 积日 ÷ 360 取余，套用年计九宫规则 | 简化分层，模板统一 | “积日去三百六十，余者入局” |
| 福应经派 | 积日运算同金镜；按宋代节气校正余数，绑定阴阳 | 算法同形，节气修正为独有特征 | “随节气定阴阳，日局从之” |
| 统宗派 | 积日入九宫，但定目、星神改用月计逻辑；阴阳二分 | 九宫入局 + 十六神星神混合模式 | “日计兼取九宫、十六神之法” |
| 淘金歌派 | 甲子日起1宫，每日顺行一宫，60日循环 | 纯干支轮宫，无复杂运算 | “甲子日头起一宫，日日顺行不改动” |

##### 1.4 时计入局
| 流派 | 计算步骤 | 校验要点 | 原文典型关键词 |
| ---- | ---- | ---- | ---- |
| 金镜派 | 积时 ÷ 72 取余，复用年计九宫顺逆 | 时局依附年计，无独立七十二局概念 | “时计从元法，循九宫” |
| 福应经派 | 积时 ÷ 72 取余；阳局起武德、阴局起吕申 | 入局绑定十六神起点，主客联动 | “阳起武德，阴起吕申，时局定焉” |
| 统宗派 | 1.积时 ÷ 72 定局数<br>2.冬至后阳局、夏至后阴局，阳顺阴逆、起止对冲 | **七十二阴阳局为核心，算法完全独立** | “时计阴阳七十二局，二至变局” |
| 淘金歌派 | 子时起1宫，每时顺行一宫，十二时循环，依附当日宫位 | 与时辰干支绑定，极简轮宫 | “子时起首顺行游，十二时中定局头” |

### 模块2：主客定算（天目/客目/主算/客算，核心占验模块）
> 天目=主目，始击=客目；主算、客算为四派差异重灾区

| 校验项 | 金镜派 | 福应经派 | 统宗派 | 淘金歌派 | 勘校提示 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| 天目（文昌/定目） | 年支合神+太岁平移；月/时计沿用年计天目 | 阳局起武德，阴局起吕申；全计阴阳二分 | 年计：合神+太岁<br>月计：18周期+十六神<br>时计：二至分阴阳起神 | 固定口诀轮宫，无18周期运算 | 统宗**四计天目分三套规则**，是核心区分点 |
| 客目（始击） | 固定取天目对冲宫，无阴阳变化 | 天目对冲，阳顺取、阴逆取，打破固定对称 | 天目对冲，额外绑定天时星、十六神 | 直接取天目对冲，规则最简 | 福应经、统宗客目有附加规则，金镜/淘金歌最直白 |
| 主算规则 | 单向顺行，止于太乙前一宫；顺逆规则粗略 | 阳局顺行、阴局逆行，起止点重新定义 | 年计：顺行至太乙前一<br>月计：十六神间起止<br>时计：阳顺阴逆、起止对冲 | 固定顺行3宫，步数固化，不计精细数理 | 时计主算**阳阴起止对冲**是统宗独有特征 |
| 客算规则 | 与主算对称，顺行至客目前一宫 | 绑定十六神（阳和德、阴大武），自成体系 | 月/时计客算起神独立，与主算分离 | 固定顺行3宫，与主算对称简化 | 福应经、统宗客算深度绑定十六神 |

### 模块3：星神系统（十精、十六神、三基、大小游、辅星）
#### 3.1 十精太乙（天皇/帝符/天时/飞鸟/五行等）
| 流派 | 运行载体 | 周期与起宫 | 校验要点 |
| ---- | ---- | ---- | ---- |
| 金镜派 | 纯九宫，不入十六神 | 大周+小周除积年，统一起1宫顺行 | 十精全程九宫，规则统一无分化 |
| 福应经派 | 九宫为主，兼入十六神（过渡形态） | 微调小周数值；天时起吕申（十六神），阳顺阴逆 | 从纯九宫转向九宫+十六神混用 |
| 统宗派 | 年计走九宫，月/日/时计走十六神 | 周期保留，起宫全部改为十六神序列，四计分立 | 十精**两套运行载体**，为本派标志性特征 |
| 淘金歌派 | 仅年计启用，月/时计直接照搬年局 | 舍弃大周，仅留小周，固定起宫 | 十精沦为附属，无独立运算 |

#### 3.2 十六神体系
| 流派 | 定位与用法 | 起法/序列 | 校验要点 |
| ---- | ---- | ---- | ---- |

| 福应经派 | 阴阳局核心，主客判定依托十六神 | 阳武德、阴吕申，对冲定起点 | 阴阳二遁完全依托十六神 |

| 淘金歌派 | 压缩为8神，仅辅助断吉凶 | 口诀化简化，顺逆永久固定 | 删减神名，不参与核心入局计算 |

## 三、高频易错点校验清单（避坑专用）
> 原文勘校、排盘最容易混淆的边界点，逐条标注区分
1. **积年混淆**
   - 金镜/福应经：公元前1936558年；统宗：公元前10153917年；淘金歌：近世截元。**看到超大积年先区分这两组数字**。
2. **月计定目区分（核心易错）**
   - 金镜：月计天目=年计天目；统宗：月计天目=18周+十六神；二者绝对不能互通。
3. **时计主算起止（标志性差异）**
   - 金镜/福应经：无论阴阳，主算均止太乙前一宫；
   - 统宗：阳局止前一、阴局止后一（对冲），**见此规则直接判定为统宗体系**。
4. **十六神优先级**
   - 金镜：九宫 > 十六神；统宗（月/时计）：十六神 > 九宫；福应经：二者并重。
5. **四计复用规则**
   - 金镜：全计**模板复用**；统宗：全计**规则分立**；这是两派最本质分界。
6. **《太乙指津》附属校验**
   - 属于**统宗分支**，仅修改上元积年（改用公元423年），其余算法完全遵从统宗，不属于独立流派。

## 四、快速判定流派流程（现场核验步骤）
拿到一段太乙原文/算法条文，按以下顺序10秒定位流派：
1. 看**上元积年** → 区分金镜/福应经、统宗、淘金歌三大阵营；
2. 看**月计定目** → 套用年计=金镜系；独立十六神=统宗；口诀轮宫=淘金歌；
3. 看**时计主算阴阳起止** → 对冲起止=统宗；单纯阳顺阴逆=福应经；单向顺行=金镜；
4. 看**十六神地位** → 核心运算单元=统宗/福应经；单纯附属=金镜；删减简化=淘金歌；
5. 看**断语内容** → 兵战灾疫=福应经；全维度细分=统宗；人事家常=淘金歌；天文国运=金镜。

## 前置通用规范（两派四计全局统一）
### 1.1 太乙九宫定义 & 本数（核心基准，**不入中五宫**）
太乙专用九宫序列（顺行遍历顺序）、卦位、宫本数一一对应，全计算以此为准：

| 宫序 | 卦名 | 宫本数 | 备注 |
| ---- | ---- | ------ | ---- |
| 一宫 | 乾   | 1      | 八宫遍历起点 |
| 二宫 | 离   | 2      | |
| 三宫 | 艮   | 3      | |
| 四宫 | 震   | 4      | |
| 五宫 | 中宫 | —      | 所有神将**永不入中五**，遍历时直接跳过 |
| 六宫 | 兑   | 6      | |
| 七宫 | 坤   | 7      | |
| 八宫 | 坎   | 8      | |
| 九宫 | 巽   | 9      | |

八宫遍历队列（剔除中五，顺行固定顺序）：
$$\boldsymbol{taiYiPalaceOrder} = [乾, 离, 艮, 震, 兑, 坤, 坎, 巽]$$
对应索引：`0:乾,1:离,2:艮,3:震,4:兑,5:坤,6:坎,7:巽`

> 规则说明：所有“前一宫/后一宫”**均基于此8宫索引做±1，模8循环**，地理方位不参与计算。

### 1.2 累加求和 & 满十去十 通用规则（三算共用）
设：顺行途经所有宫的**宫本数累加和**为 $S$，最终有效算数为 $N$。
1. 累加范围：**从起点宫出发，顺行途经每一个宫，直到终点宫的前一宫停止**（终点宫本身不计入累加）。
2. 取数规则（古籍标准「满十去十，零为算」，无额外50取模规则）：
   $$N = ((S - 1) \bmod 10) + 1$$
   - 效果：结果固定落在 $[1,10]$
   - 特例：$S$ 为10/20/30…整十数时，结果强制为 $10$

### 1.3 边界特例：无算（全局统一）
满足以下任一条件，**累加和 $S=0$，判定为【无算】**：
1. 计算起点（文昌/始击/定大将）与太乙落宫**同宫**；
2. 起点顺行一步即抵达太乙宫（中间无任何途经宫）。

### 1.4 十六神与宫位映射（时计专用）
十六神绑定八宫正位，用于时计起点神（文昌、武德、吕申）转宫位，提供函数：
- `sixteenGodPosition(神名)`：十六神 → 序列位置
- `palaceToZhengDeityPosition(宫位)`：八宫 → 对应十六神正位

### 1.5 阴阳遁判定规则（全局时计/日计共用）
以**精确节气交节时刻**为分界（弃用固定6.21/12.22）：
- **阳遁**：冬至交节时刻 ～ 夏至交节时刻
- **阴遁**：夏至交节时刻 ～ 冬至交节时刻
- 行走方向：所有计法**默认顺时针顺行**；阴阳遁仅改变**起点神/终点宫偏移**，不改变行进方向。

# 第一部分：金镜派（《太乙金镜式经》）完整算法
## 总述
金镜派：**年/月/日三计规则完全一致**；时计独立规则；积年体系以**唐天宝十载(751年)** 为上元基准；月计、日计采用**连续积算**，不独立起局。

## 2.1 基础入局公式（金镜专用积年体系）
### 2.1.1 绝对积年
$$\text{绝对积年} = 10153917 + (Y - 751)$$
$Y$：目标公元年份

### 2.1.2 年入纪元数
$$Yr = \text{绝对积年} \bmod 360$$
若 $Yr=0$，强制赋值 $Yr=360$（五元六纪，周期360）

### 2.1.3 月入纪元数（积月连续推算）
$$\text{总积月} = \text{绝对积年} \times 12 + M$$
$M$：当年目标月份
$$Mo = \text{总积月} \bmod 360$$

### 2.1.4 日入纪元数（积日连续推算）
采用古岁实 $365.2425$ 日/年：
$$\text{总积日} = \text{绝对积年} \times 365.2425 + D$$
$D$：当年年内累计日数
$$Da = \text{总积日} \bmod 360$$

### 2.1.5 时入纪元数（基于当日积日）
时辰序数：子时=1、丑时=2 … 亥时=12
$$\text{总积时} = \text{当日积日} \times 12 + H$$
$H$：目标时辰序数
$$Hr = \text{总积时} \bmod 360$$

### 2.1.6 神将定位通用规则（金镜四计）
通过对应纪元数（$Yr/Mo/Da/Hr$）分别计算：
- $P_{ty}$：太乙落宫（八宫）
- $P_{wc}$：文昌（天目）落宫（主算起点）
- $P_{sj}$：始击（客目）落宫（客算起点）
- $P_{ddj}$：定大将落宫（定算起点）

---

## 2.2 金镜派 · 年计（岁计）三算
### 核心规则
- 行进方向：**顺时针顺行**
- 统一起止：起点=对应神将落宫，**终点=太乙前一宫**（8宫索引 $\text{index}(P_{ty})-1 \pmod{8}$）
- 适用：主算、客算、定算

#### 2.2.1 主算（文昌起算）
1. 取年文昌落宫 $P_{wc}$（起点）、年太乙落宫 $P_{ty}$
2. 计算终点宫：
   $$\text{endPalace} = taiYiPalaceOrder\big[(\text{index}(P_{ty}) - 1) \bmod 8\big]$$
3. 从 $P_{wc}$ 顺时针遍历，累加途经宫本数得到 $S$；触发「无算」则 $S=0$
4. 套用**满十去十公式**得到最终主算数 $N$

#### 2.2.2 客算（始击起算）
流程、起止、累加规则**完全同主算**，仅更换起点：
1. 起点：年始击落宫 $P_{sj}$
2. 终点：同上（太乙前一宫）
3. 求和、取数规则一致

#### 2.2.3 定算（定大将起算）
流程、起止、累加规则**完全同主算**，仅更换起点：
1. 起点：年定大将落宫 $P_{ddj}$
2. 终点：同上（太乙前一宫）
3. 求和、取数规则一致

---

## 2.3 金镜派 · 月计 三算
**规则与年计100%一致**，仅替换为月维度神将落宫：
1. 数据源：月入纪元数 $Mo$ → 求得 $P_{ty}$(月太乙)、$P_{wc}$(月文昌)、$P_{sj}$(月始击)、$P_{ddj}$(月定大将)
2. 起止、顺行、累加、满十去十、无算边界：**复用年计全部逻辑**

---

## 2.4 金镜派 · 日计 三算
**规则与年计100%一致**，仅替换为日维度神将落宫：
1. 数据源：日入纪元数 $Da$ → 求得日维度四大神将落宫
2. 起止、顺行、累加、满十去十、无算边界：**复用年计全部逻辑**

> 小结：金镜 **年/月/日三计为同一套代码分支**，仅神将定位数据源不同。

---

## 2.5 金镜派 · 时计 三算（独立规则）
### 基础规则
1. 行进方向：永久**顺时针顺行**，不分阴阳遁
2. 起点统一：**固定以文昌为起点**（不分阳遁/阴遁）
3. 终点统一：固定为**太乙前一宫**（无阴阳偏移）

#### 2.5.1 主算
1. 起点：时文昌对应十六神位置
2. 终点：太乙前一宫 → 转十六神正位
3. 顺行累加、满十去十、无算边界：通用规则

#### 2.5.2 客算
起点：时始击对应十六神位置，其余规则同主算。

#### 2.5.3 定算
起点：时定大将对应十六神位置，其余规则同主算。

# 第二部分：统宗派（《太乙统宗宝鉴》）完整算法
## 总述
统宗派：上元基准、起局逻辑与金镜完全不同；**年/月/日计规则对齐金镜**；**时计为核心差异点**（阴阳遁区分起点、终点偏移）；月计、日计支持独立起局与时令入局两套逻辑。

## 3.1 基础入局公式（统宗专用积年体系）
### 3.1.1 绝对积年（明崇祯十七年1644年为上元）
$$\text{绝对积年} = 10155960 + (Y - 1644)$$
$Y$：目标公元年份

### 3.1.2 年入纪元数
$$Yr = \text{绝对积年} \bmod 360$$
周期360，余数为0则取360。

### 3.1.3 月计入局（双模式）
1. 传统积月模式（兼容古法）：同金镜积月计算
2. 独立起局模式（统宗特色）：依当年年干支、正月建寅，按月干支直接定月局，**不依赖大积年**

### 3.1.4 日计入局（独立起局）
以**冬至后首个甲子日 / 夏至后首个甲子日**为基准，计算距离基准日的累积天数为日局数，不再使用连续积日。

### 3.1.5 时计入局（独立起局）
依当日日干，用五鼠遁排当日时辰干支，以时辰甲子序列为时局数。

### 3.1.6 神将定位
通过对应纪元数/局数，分别求得四神将落宫：$P_{ty}、P_{wc}、P_{sj}、P_{ddj}$。

---

## 3.2 统宗派 · 年计 三算
**与金镜年计规则完全一致**：
- 顺行、起点定义、终点（太乙前一宫）、累加、满十去十、无算边界全部复用。

## 3.3 统宗派 · 月计 三算
**与金镜月计规则完全一致**：
仅入局方式可选「积月/独立干支起局」，三算计算逻辑无差异。

## 3.4 统宗派 · 日计 三算
**与金镜日计规则完全一致**：
仅入局方式改为「冬至/夏至甲子日起算」，三算计算逻辑无差异。

> 小结：统宗 **年/月/日三计 计算逻辑 ≡ 金镜**，差异仅在**前置入局求局数**环节。

---

## 3.5 统宗派 · 时计 三算（核心差异，重点实现）
### 全局前置规则
1. 行进方向：**永久顺时针顺行（clockwise=true）**
2. 阴阳遁分界：精确冬至/夏至交节时刻
3. 核心变化：**起点神 + 终点宫偏移** 随阴阳遁切换

### 3.5.1 起点神规则（统宗时计专属）
- 阳遁（冬至→夏至）：起点神 = **武德**
- 阴遁（夏至→冬至）：起点神 = **吕申**

### 3.5.2 终点宫偏移规则（统宗时计专属）
基于八宫序列 `taiYiPalaceOrder`：
- 阳遁：终点 = 太乙**前一宫** $\quad \text{index}(P_{ty})-1 \pmod{8}$
- 阴遁：终点 = 太乙**后一宫** $\quad \text{index}(P_{ty})+1 \pmod{8}$

### 3.5.3 主算（统宗时计）
1. 根据阴阳遁取起点神（武德 / 吕申），转为十六神位置 `startPos`
2. 根据阴阳遁计算终点宫，转为十六神正位 `endPos`
3. 顺时针顺行累加途经宫本数得 $S$
4. 触发边界则 $S=0$，再执行满十去十得到结果

### 3.5.4 客算（统宗时计）
1. 固定起点：时始击对应十六神位置
2. 终点规则、行进方向、求和、取数、边界：**同主算**

### 3.5.5 定算（统宗时计）
1. 固定起点：时定大将对应十六神位置
2. 终点规则、行进方向、求和、取数、边界：**同主算**

# 第五部分：补充说明（开发排坑要点）
1. **中五宫屏蔽**：所有遍历逻辑必须跳过五宫，八宫循环只在 `taiYiPalaceOrder` 8个宫内执行。
2. **索引循环**：所有±1操作必须加 `mod 8`，防止数组越界。
3. **十六神↔八宫转换**：时计必须先把「神位」转「宫位」，再执行八宫遍历累加。
4. **无算优先级**：先判断边界返回0，再执行累加计算。
5. **向后兼容**：原有测试向量（孔令伟/鹰蛇太乙）完全匹配本套规则，回归测试可直接复用。

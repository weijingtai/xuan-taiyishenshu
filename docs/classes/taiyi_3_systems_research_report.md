# 太乙三大算法体系调研报告

本报告旨在阐明您所关注的三个太乙神数分支的算法核心、关键步骤及主要区别。调研结果主要依赖于项目内部的高质量文档，如 [4_classes_explain.md](file:///Users/jingtaiwei/Git/Public/xuan-migration/xuan-taiyishenshu/docs/classes/4_classes_explain.md) 和 [ming_fa_vs_ming_gua_2.md](file:///Users/jingtaiwei/Git/Public/xuan-migration/xuan-taiyishenshu/docs/classes/ming_fa_vs_ming_gua_2.md)，并结合了网络公开信息进行佐证。

### **一、 《福应经派》算法调研**

**1. 核心定位与算法来源**
- **定位**：宋代官方实战派，侧重于兵占、灾祥、疾疫等具体事件的预测。
- **来源**：算法框架继承自唐代的《太乙金镜式经》，但进行了重要修正以适应宋代历法和实战需求。

**2. 关键算法特征**
- **上元积年**：沿用《金镜》的天文积年体系（原点为公元前1936558年），但根据宋代历法进行了微调。
- **阴阳分局**：这是《福应经派》最核心的创新。它在《金镜》派单纯的顺逆行基础上，引入了严格的阴阳二遁（二局）概念，贯穿于入局、定目、主客算等各个环节。
    - **天目起法**：阳局从**武德宫**起，阴局从**吕申宫**起，这直接改变了星神定位的基准。
- **主客算规则**：主算和客算的计算也因阴阳局的引入而变得更加复杂，例如客算会绑定特定的十六神（如阳局起和德，阴局起大武），使其判断更具针对性。

**3. 调研结论**
- **资料稀缺**：尽管项目内部文档提供了高质量的规则对比，但网络上极度缺乏可直接用于编程的、关于《福应经派》算法的详细数学步骤和实例。例如，“月计余数除18定阴阳”、“日计按节气修正”等关键操作，其具体实现细节仍然未知。
- **小结**：目前仅能还原其宏观算法规则，无法精确复现其完整的计算过程。

### **二、 《太乙人道命法（命盘）》算法详解**

**1. 核心定位与算法来源**
- **定位**：源自《太乙统宗宝鉴》的个人命运推演模型，是太乙“局法”在人事领域的应用延伸。
- **来源**：基于《统宗》的时计局法，并融合了后世发展的十二人身宫体系。

**2. 算法核心步骤**
- **第1步：计算总积时**
    - **基准**：采用《统宗》上元积年 `10153917`。
    - **公式**：`总积时 = ( (出生年份 + 10153917) * 365 + 当年累计天数 ) * 12 + 时辰序数`
- **第2步：时局入局（定太乙落宫）**
    - **公式**：`总积时 % 72`，取余数（1-72）作为时局数。
    - **阴阳局**：以冬至/夏至为界，判断阴阳局。
    - **落宫**：根据时局数将太乙布入九宫（中五宫除外）。
- **第3步：定天目（文昌）与始击**
    - **天目**：阳局自**武德**起顺行十六神，阴局自**吕申**起逆行十六神。
    - **始击**：固定为天目的对冲宫位。
- **第4步：计算主算与客算**
    - **主算**：从天目起，阳顺阴逆，计宫数。其**止点**是统宗派的标志性规则：**阳局止于太乙前一宫，阴局止于太乙后一宫（对冲修正）**。
    - **客算**：从始击起，规则与主算完全同步。
- **第5步：星神与十二宫映射**
    - 将计算出的各类星神（如十精、三基等）的落宫，与代表个人不同生活领域的十二人身宫（命宫、财帛、官禄等）进行对应，从而解读吉凶。

**3. 调研结论**
- **算法清晰**：得益于内部文档的详细拆解，其算法框架和关键计算节点都非常明确，具备了编程实现的基础。

### **三、 《太乙命卦（统运入卦）》算法详解**

**1. 核心定位与算法来源**
- **定位**：同样源自《太乙统宗宝鉴》，但属于独立的“卦运”体系，用于推演国运、大运趋势或个人一生基调。
- **来源**：《统宗》卷十三“太乙统运入卦纪年术”。

**2. 算法核心步骤**
- **第1步：取太乙积年**
    - **基准**：同上，采用《统宗》积年 `10153917`。
    - **公式**：`总积年 = 目标年份 + 10153917`
    - **注意**：此法**只用年份**。
- **第2步：取余数定【本卦】**
    - **公式**：`总积年 % 64`，取余数（0-63）。
    - **定卦**：余数对应卦的序号（余1为第1卦，余0为第64卦）。
    - **核心**：必须使用 **《太乙统宗》专属的六十四卦序**，而非通行的《周易》卦序。
- **第3步：定【动爻】**
    - **阴阳辰**：根据年份的干支组合判定。
    - **取爻位**：复用上一步的**余数**。
    - **排布规则（铁律）**：
        - **阳辰**：从**初爻（下）往上**数。
        - **阴辰**：从**上爻（上）往下**数。
- **第4步：生成【变卦】**
    - 将本卦的动爻进行阴阳反转，即生成变卦，用于解读后续运势变化。

**3. 调研结论**
- **算法独立且完整**：这是一个与局法完全不同的、基于模64和卦爻变化的独立系统。内部文档已提供了完整且清晰的算法流程和所有关键校验点。

### **总结**

本次调研成功地厘清了《太乙人道命法》和《太乙命卦》的完整算法脉络，二者均可基于现有资料进行后续的开发。而《福应经派》由于公开资料的限制，目前只能停留在理论规则层面，尚不具备完整复现的条件。

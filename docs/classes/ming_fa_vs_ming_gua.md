## 1. 引言
本报告旨在深度解析并对比太乙体系下两大独立分支——**太乙人道命法（个人命盘）**与**太乙命卦（统运入卦）**的算法逻辑、起算流程及关键校验点。二者虽同源于太乙神数的积年与周期理论，但其底层模型、应用场景和操作细节存在根本性差异。报告将基于《太乙统宗宝鉴》原文框架，对两种方法进行拆解、对比与校验说明，为后续勘校与应用提供清晰的参照标准。

## 2. 体系定位与核心区别
### 2.1 体系定位
- **太乙人道命法**：以《太乙统宗宝鉴》局法为基础，融合十二宫人事框架，是**“局法+身命”的个人命运推演模型**，属于太乙局法的应用延伸。
- **太乙命卦（统运入卦）**：将太乙积年与六十四卦相结合，是**“时间周期+卦爻”的国运/大运推演模型**，属于太乙卦运体系，独立于九宫局法之外。

### 2.2 核心区别概览
| 对比维度 | 太乙人道命法（命盘） | 太乙命卦（统运入卦） |
| :--- | :--- | :--- |
| **底层模型** | 九宫局法 + 十六神 + 主客算 + 十二宫 | 太乙积年 + 六十四卦 + 爻变 |
| **核心运算** | 积时入局 → 定宫定星 → 星神落十二宫 | 积年 ÷ 64 → 定卦 → 定动爻 |
| **核心元素** | 太乙、文昌、始击、主客算、三基、十二宫 | 卦体、爻位、动爻、变卦、太乙卦序 |
| **主要用途** | 个人六亲、事业、健康、吉凶方位 | 国运兴衰、朝代更替、大运趋势、本命基调 |
| **流派归属** | 统宗局法体系（应用层） | 统宗卦运体系（独立分支） |

## 3. 太乙人道命法（命盘）算法详解与校验要点
> 参考依据：《太乙统宗宝鉴》卷十八、十九时计局法及后世《太乙人道命法》衍生体系。

### 3.1 算法总览
太乙人道命法的核心逻辑是：**将出生时间转化为太乙时局，再将时局中的星神映射到十二宫，以此解读个人命运**。其流程分为五大阶段：**积时入局 → 定阴阳局 → 主客定算 → 星神定位 → 十二宫映射**。

### 3.2 分步算法详解
#### 3.2.1 第一步：积时入局（时计局法）
1.  **起算基准**：采用《统宗》上元积年，计算至出生时刻的**积时**（总时数）。
    *   公式：`积时 = (年积年 × 365 + 月日数) × 12 + 时辰序数`
2.  **入局计算**：
    *   `积时 ÷ 72` 取余数，余数对应**太乙时局数（1-72局）**。
    *   根据局数确定太乙落宫（九宫，不入中五）。
    *   **校验要点**：局数必须与节气对应，冬至后阳局、夏至后阴局，二至交节换局。

#### 3.2.2 第二步：定阴阳局与顺逆
1.  **阳遁/阴遁判定**：
    *   冬至后用**阳局**，夏至后用**阴局**。
    *   阳局顺行，阴局逆行。
2.  **关键规则**：
    *   阳局：文昌起武德宫顺行，主算顺行。
    *   阴局：文昌起吕申宫逆行，主算逆行。
    *   **校验要点**：此为《统宗》时计核心，与金镜派的“单向顺行”有本质区别。

#### 3.2.3 第三步：主客定算（核心校验点）
1.  **定天目（文昌/主目）**：
    *   阳局起武德宫，阴局起吕申宫，顺行十六神定天目位置。
2.  **定始击（客目）**：
    *   天目对冲宫为始击（客目）。
3.  **主算/客算计算**：
    *   主算：从天目起，阳局顺行、阴局逆行，至太乙前一宫止（阴局则为后一宫，对冲修正），累计宫数。
    *   客算：从始击起，同法计算。
    *   **校验要点**：主算与客算的起止点必须严格遵循《统宗》时计规则，与年计通用模板不同。

#### 3.2.4 第四步：星神定位（十精、三基、辅星）
1.  **十精太乙**：
    *   天皇、帝符、天时等十星，根据时局数与十六神序列定位。
    *   **校验要点**：月/时计十精行十六神，而非九宫，此为统宗特有。
2.  **三基（君/臣/民基）、大小游**：
    *   按各自周期起宫，阳顺阴逆分局。
3.  **辅星（计神、文昌、始击）**：
    *   计神由主算起点决定，文昌、始击与天目绑定。

#### 3.2.5 第五步：十二宫映射（人道专属）
1.  **十二宫定义**：命宫、父母、兄弟、妻妾、子孙、财帛、田宅、官禄、奴仆、疾厄、福德、相貌。
2.  **映射规则**：
    *   以命宫（通常为出生年支或时支落宫）为基准，将时局中的星神按宫位映射到十二宫。
    *   **校验要点**：此步骤为后世衍生，《统宗》原文无明确十二宫映射条文，不同版本映射规则可能存在差异。

### 3.3 关键注意事项与避坑指南
1.  **积年基准必须用统宗**：金镜派积年不同，入局结果会完全不同。
2.  **阴阳局不可混淆**：阳局顺行、阴局逆行是核心，混用会导致星神位置全错。
3.  **时计主算起止特殊**：阴局主算止太乙后一宫，不可套用年计“前一宫”模板。
4.  **十二宫映射为衍生内容**：无统一标准，解读时需明确所用版本的映射规则。

## 4. 太乙命卦（统运入卦）算法详解与校验要点
> 参考依据：《太乙统宗宝鉴》卷十三“太乙统运入卦纪年术”。

### 4.1 算法总览
太乙命卦的核心逻辑是：**以太乙积年为模数，通过除以64的周期运算，匹配太乙专属卦序，定本命/流年卦，并以动爻解读运势**。其流程分为四大阶段：**取积年 → 定卦 → 定动爻 → 断卦**。

### 4.2 分步算法详解
#### 4.2.1 第一步：取太乙积年
1.  **起算基准**：采用《统宗》上元积年，计算至目标年份的**积年数**。
    *   公式：`积年 = 目标年份 + 10153917`（公元后）
2.  **校验要点**：必须使用统宗积年，金镜派积年不同，入卦结果无法通用。

#### 4.2.2 第二步：定卦（太乙卦序）
1.  **入卦计算**：
    *   `积年 ÷ 64` 取余数（0-63）。
    *   余数0对应第64卦（未济），余数1对应第1卦（乾），以此类推。
2.  **太乙卦序**：
    *   采用太乙专属的六十四卦排列顺序，**与《周易》通行卦序不同**。
    *   **校验要点**：卦序是关键，使用通行卦序会导致卦象完全错误。

#### 4.2.3 第三步：定动爻（关键步骤）
1.  **阴阳辰判定**：
    *   看年份干支：阳干阳支为阳辰，阴干阴支为阴辰。
2.  **动爻规则**：
    *   阳辰：从**初爻往上数**，数尽余数落在哪一爻即为动爻。
    *   阴辰：从**上爻往下数**，数尽余数落在哪一爻即为动爻。
3.  **变卦生成**：
    *   动爻一变，生成变卦，主后事或下半年运势。
    *   **校验要点**：动爻起算方向与阴阳辰绑定，不可随意起算。

#### 4.2.4 第四步：断卦逻辑
1.  **卦义解读**：依据太乙卦序的专属卦义，而非通用周易卦辞。
2.  **爻变分析**：结合动爻爻辞、变卦卦象，解读运势变化趋势。
3.  **大运推演**：以每12年或60年为单位，推演大运卦象变化。

### 4.3 关键注意事项与避坑指南
1.  **积年与卦序必须匹配**：统宗卦序仅适配其自身积年体系，不可用其他太乙积年或卦序替代。
2.  **动爻规则是核心**：阳辰从下数、阴辰从上数，是区分太乙命卦与普通纳甲筮法的关键。
3.  **卦义解读需参考太乙原文**：太乙卦序的卦义侧重国运兴衰，与《周易》通行解读不同。
4.  **不可与太乙局法混用**：命卦与局法是两套独立系统，不可将局法中的星神与命卦卦象强行关联。

## 5. 核心差异总结与避坑指南
### 5.1 核心差异总结
| 对比项 | 太乙人道命法（命盘） | 太乙命卦（统运入卦） |
| :--- | :--- | :--- |
| **模型核心** | 九宫局法 + 十六神 + 十二宫 | 积年 ÷ 64 + 太乙卦序 + 动爻 |
| **运算周期** | 局数72、天目18、九宫9 | 卦周64 |
| **阴阳处理** | 阳顺阴逆，影响星神位置 | 仅影响动爻起算方向 |
| **解读维度** | 星神落宫、主客胜负、六亲吉凶 | 卦象、爻变、否泰趋势 |
| **原文出处** | 《统宗》局法衍生 | 《统宗》卷十三专篇 |

### 5.2 避坑指南
1.  **体系不可混淆**：二者是完全独立的算法，不可将命盘的星神位置套入命卦解读。
2.  **基准不可混用**：两种方法都必须以《统宗》的上元积年为基准，否则结果无校验意义。
3.  **规则不可简化**：命法的阴阳顺逆、命卦的动爻方向是硬性规则，简化或套用通用模板会导致核心错误。
4.  **解读需结合场景**：命法侧重个人具体事项，命卦侧重长期趋势与国运，解读时需区分应用场景。

## 结论
太乙人道命法与太乙命卦是太乙体系中两条并行不悖的分支，分别代表了“局法人用化”与“卦运独立化”的发展路径。二者虽同源，但底层逻辑、运算流程和应用场景截然不同。在研究与应用中，必须严格区分其算法规则与校验标准，以确保解读的准确性与一致性。

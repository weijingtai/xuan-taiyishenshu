先把关键点说清楚：

1. **《太乙统宗宝鉴》里没有“十四卦序列”这个固定名词**。  
2. 你要的应该是：
   - 要么：**太乙统宗专属六十四卦序（用于命卦/统运入卦）**；
   - 要么：**“十二运”里的关键十四卦（十二运共64卦，常被拎出的核心运卦）**。

从你前面问“统宗专属太乙十四卦序列表”，结合《统宗》原文，最贴近的是：
- **十二运体系中，每运取代表卦，合计约14个核心运卦**（民间简称“十四运卦”）。

# 二、太乙统宗十二运·十四核心卦（卷十四原文+年数+灾异）
### 【原文总纲（卷十四）】
> **明太乙统十二运卦象之术上**  
> 其一曰天地否泰之运。夫易有太极，而生两仪。乾，天之体也，而运乎上；坤，地之质也，而止乎下。天地既判，其气未交而为否，气既交而为泰，故为天地泰否之运，始于乾，终于泰，四卦七百二十年，卦体天地否泰之象焉。

### 【十二运+十四核心卦（原文+年数+灾异）】
## 运1：天地否泰之运（4卦 → 核心4卦）
**原文**：始于乾，终于泰，四卦七百二十年。  
- 乾：216年 → 偏阳，多旱；君宜勤政自强  
- 坤：144年 → 偏阴，多雨；女主、臣强  
- 否：180年 → 天地不交，闭塞；灾旱、兵起  
- 泰：180年 → 阴阳和，风雨时；国泰民安  
**核心卦：乾、坤、否、泰**

## 运2：男女交亲之运（12卦 → 取4核心）
**原文**：自震至咸，共二千一百六十年。  
- 震：长男；动、兵、惊  
- 咸：少男少女；婚姻、交感  
- 既济：水火交，六爻正；治世、功成  
- 未济：水火不交；终乱、后事难  
**核心卦：震、咸、既济、未济**

## 运3：阳晶守政之运（6卦 → 取2核心）
**原文**：大壮至遁，共一千一百五十二年。  
- 大壮：阳盛；征伐、武功  
- 遁：阳退；隐退、避祸  
**核心卦：大壮、遁**

## 运4：阴毳权衡之运（6卦 → 取2核心）
**原文**：自观至升，共一千〇〇八年。  
- 观：阴盛；观政、女主  
- 升：阴气上长；渐进、臣升  
**核心卦：观、升**

## 运5：资育还本之运（6卦 → 取2核心）
**原文**：自豫至谦，共九百三十六。  
- 豫：乐、散；逸乐、荒政  
- 谦：谦退；和、免灾  
**核心卦：豫、谦**

## 运6：造化符天之运（6卦 → 取2核心）
**原文**：小畜至履，共一千二百二十四年。  
- 小畜：密云不雨；蓄养、未达  
- 履：践危；谨慎、履险  
**核心卦：小畜、履**

（运7–运12为延伸，无专属核心名，民间只取前6运**14卦**为“太乙十四运卦”）

# 三、统宗 vs 金镜/通行序·关键差异（原文对照）
## 1. 积年不同（最根本）
- 统宗：**10153917**（卷十三）  
- 金镜：10153919（差2年，全盘错位）

## 2. 卦序不同（命卦必错点）
- 统宗：见上文64序（卷十三原文）  
- 周易通行：乾、坤、屯、蒙、需、讼、师、比、小畜、履、泰、否、同人、大有、谦、豫、随、蛊、临、观、噬嗑、贲、剥、复、无妄、大畜、颐、大过、坎、离、咸、恒、遁、大壮、晋、明夷、家人、睽、蹇、解、损、益、夬、姤、萃、升、困、井、革、鼎、震、艮、渐、归妹、丰、旅、巽、兑、涣、节、中孚、小过、既济、未济（第43位为夬，统宗为姤）

## 3. 动爻规则不同（统宗独有）
- 统宗：**同余数定卦+定动爻；阳辰从下往上，阴辰从上往下**（卷十六）  
- 金镜：动爻另取数；或用纳甲起爻，**不可混用**

# 第二部分 上篇：太乙人道命法（命盘）速查+逐点校验
## 模块1：完整起盘流程（标准五步）
### 步骤1：计算总积时（入局前置）
1. 先算**年积年**：\(年积年 = 出生年份 + 10153917\)
2. 换算日积：\(日积 = 年积年 \times 365 + 当年月日累计天数\)
3. 换算总积时：\(\boldsymbol{总积时 = 日积 \times 12 + 时辰序数}\)
   > 时辰序数：子=0/1、丑=2……亥=11（按所用版本统一即可）

**校验要点**
- 积时基数必须沿用统宗上元，换其他积年则全盘作废。
- 闰月、闰日按**节气**校正，不按农历月份硬算。

### 步骤2：时局入局（定72阴阳局、太乙落九宫）
公式：\(\boldsymbol{总积时 \div 72 = 商 \cdots\cdots 余数}\)
1. 余数 = 时局数（1~72，余0作72局）
2. 依时局数 + 节气，判定**阳局/阴局**
3. 由时局数定位**太乙本宫（九宫，中五宫不入）**

**校验要点&易错警示**
- 72局分阴阳各36局，冬至阳局、夏至阴局，二至分界不可错乱。
- 太乙固定不入中五宫，凡排盘中太乙落中五，必为计算错误。

### 步骤3：定天目（文昌/主目）、始击（客目）
1. 阳局：自**武德**起，顺行十六神，定天目位置
2. 阴局：自**吕申**起，逆行十六神，定天目位置
3. 始击（客目）：**天目对冲宫**，阴阳局通用此规则

**校验要点&易错警示**
- 人道命法天目 = 统宗时计天目规则，**不套用年计合神平移法**。
- 十六神序列严格遵从统宗原版，不得删减、调换神位顺序。

### 步骤4：计算主算、客算（命盘核心：主筹/客筹）
#### 主算规则
- 阳局：从天目起，**顺行**，止于**太乙前一宫**，累计宫数=主算
- 阴局：从天目起，**逆行**，止于**太乙后一宫（对冲修正）**，累计宫数=主算

#### 客算规则
- 以始击（客目）为起点，顺逆、起止规则**完全同步主算**，得数=客算

**校验要点&高频坑（重中之重）**
1. 阴局起止点和年计模板不同，**不可一律取“太乙前一宫”**。
2. 正宫、间辰起算规则沿用统宗时计，不可套用金镜派算法。
3. 主算、客算数字直接对应命盘“主筹、客筹”，数字错误全盘解读失效。

### 步骤5：星神定位 + 十二人身宫映射（人道专属）
1. **辅星/十精/三基/大小游**
   - 时计体系：十精、三基、大小游**行十六神**，非纯九宫运行（统宗独有）
   - 计神：以主算起点为定位标准，区别于金镜派“太乙前一宫”规则
2. **十二人身宫（命盘外圈：命宫/六亲宫）**
   十二宫名录：**命宫、相貌、父母、兄弟、妻妾、子孙、财帛、田宅、官禄、奴仆、疾厄、福德**
   映射规则：以本命宫（多取出生时支/年支落宫）为基准，星神落宫对应人事吉凶。

**校验要点&易错警示**
- 十二宫为后世衍生内容，不同民间版本映射顺序略有差异，**以自身所用底本为准**。
- 不可将十六神、十精含义套用周易卦理解读。

# 第三部分 下篇：太乙命卦（统运入卦/太岁直卦）速查+逐点校验
## 模块1：完整起卦流程（标准四步）
### 步骤1：取用太乙积年（唯一基准）
公式（公元后）：
\[
\boldsymbol{总积年 = 目标年份 + 10153917}
\]
> 用途：流年卦取当年积年；本命卦取出生当年积年。

**校验要点**
- 本卦体系**只看年积年，不用月、日、时积数**。
- 换用其他流派积年，卦象、动卦全部失效。

### 步骤2：取余数定【本卦】（核心模数：64）
公式：
\[
\boldsymbol{总积年 \div 64 = 商 \cdots\cdots 余数 \quad (0 \le 余数 \le 63)}
\]
余数对应规则：
1. 余数 = 1 → 第1卦（乾）
2. 余数 = 2 → 第2卦（坤）……依次顺排
3. 余数 = 0 → 取第64卦（未济）

**强制校验（最容易出错）**
> 必须使用 **《太乙统宗》专属六十四卦序**
> ❌ 严禁使用：通行本《周易》卦序、京房卦序、纳甲卦序。

### 步骤3：判定阴阳辰 + 取【动爻】
1. **阴阳辰判定**
   出生/流年干支：
   - 阳干+阳支 = 阳辰
   - 阴干+阴支 = 阴辰
2. **动爻数取用**：复用上面「积年÷64」得到的**同一个余数**
3. **动爻排布规则（铁律）**
   - 阳辰：**由初爻向上数**，数至余数对应爻位 → 动爻
   - 阴辰：**由上爻向下数**，数至余数对应爻位 → 动爻

**校验要点&易错警示**
- 余数同时用来定卦、定动爻，**不二次取数**。
- 动爻方向是太乙命卦独有规则，和普通卜卦起爻完全不同。

### 步骤4：生成【变卦】+ 解读规则
1. 本卦中**唯动爻阴阳反转**，其余爻不动，即成变卦。
2. 解读分工：
   - 本卦：主一生基调、当年大势、核心吉凶
   - 变卦：主后事、下半年、运势变化、结局走向
3. 卦义：以《统宗》卦运解读为准，侧重国运、治乱、大运趋势。

1. 看到 **72局、主筹客筹、十二人身宫、十六神** → 太乙人道命法
2. 看到 **64卦、本卦变卦、上下数动爻、只论年积年** → 太乙命卦
3. 两者同时出现 → 统宗体系“局+卦”双用，分别解读，不可混断

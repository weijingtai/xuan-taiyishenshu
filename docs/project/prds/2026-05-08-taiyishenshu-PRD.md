# 太乙神数排盘 — 产品需求文档

## 元信息

- 创建日期：2026-05-08
- 版本：v1.0.0
- 状态：MVP 已交付，后续版本规划中

## 产品定位

太乙神数排盘工具，面向中国传统术数研究者和爱好者，提供三派四盘的完整排盘计算与可视化展示。

## 目标用户

- 太乙神数研究者，需要快速验算排盘结果
- 传统术数学习者，需要可视化理解排盘结构
- 民间术数实践者，需要支持多流派的排盘工具

## 核心需求

### N1：多流派排盘

用户可以选择金镜派、统宗派、集成派三种流派进行排盘。同一时间输入下，三派结果应有可解释的差异。

### N2：多盘类型支持

用户可以选择年家、月家、日家、时家四种盘类型。刻家暂不实现，但 UI 和模型中预留扩展位置。

### N3：完整排盘计算链

排盘必须覆盖完整算法链：积年计算 → 局数 → 阴阳遁 → 太乙行宫 → 文昌/天目 → 计神 → 始击 → 主客算/定算 → 大将/参将 → 八门 → 天盘星神 → 神盘星神 → 格局判断 → 九贵神排布。

### N4：可视化排盘展示

提供多种排盘可视化风格（经典放射状、罗盘风格、标准九宫格），支持用户切换。

### N5：信息面板

展示完整的排盘参数和结果信息，包括基础参数、年计数据、主客算详情、各盘星神分布、格局判断等。

## 非功能需求

### NF1：算法 UI 分离

核心排盘算法不依赖 Flutter Widget，可独立测试、独立验证。

### NF2：流派规则可配置

三派差异通过规则配置文件表达，不在 UI 层写流派判断逻辑。

### NF3：可测试性

每个关键算法步骤可单独验证。测试覆盖年家核心计算。

### NF4：本地隐私

所有用户数据默认本地处理，不上传、不同步。

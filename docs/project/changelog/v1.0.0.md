# v1.0.0 — 太乙神数排盘 MVP

## 发布日期

2026-05-08

## 概述

首次交付，实现三派年家完整排盘 + 月/日/时家基础链路 + 多风格 UI。

## 新增

### 算法

- 积年计算（金镜派古积年、统宗派古积年、集成派当代甲子元）
- 月积/日积/时积计算
- 局数计算（72 周期）
- 阴阳遁判断
- 太乙行宫（金镜/集成两套公式）
- 文昌/天目计算（含金镜/统宗重留规则）
- 计神计算（十六神/十二神两套体系）
- 始击计算
- 主客算/定算（含分步过程说明）
- 主客大将/参将落宫
- 八门排布（随宫/固定两种模式）
- 天盘星神：君基、臣基、民基、五福、大游、小游、飞符、四神、天乙、地乙、值符
- 神盘星神：太岁、岁破、值符、合神、四象（青龙/朱雀/白虎/玄武）、风伯、雨师
- 统宗派额外星神：青龙旗、黑旗、赤旗、贵神值事
- 格局判断：掩、囚、击、迫、格、对
- 九贵神排布
- 命盘：命宫/身宫 + 十二宫
- 年计参数（五子元局/元数/局数/入纪/年卦/太乙行宫参数）
- 自定义神煞框架（接口 + 仓储 + 算法模板）

### UI

- 主页面：日期时间选择 + 流派选择 + 盘类型选择 + 样式选择
- 经典放射状排盘网格（TaiYiPanGrid）
- 罗盘风格排盘网格（TaiYiPanGridV2）
- 标准 3×3 九宫格（NineGongGrid，含八卦/地支/八门/星神/阴阳数/主客算）
- 综合信息面板（PanInfoPanel，14 个分区）
- 响应式布局（宽屏并排/窄屏垂直）
- 经典主题系统（16 种命名颜色 + 八卦/地支/层级颜色映射）
- 谷歌字体集成（MaShanZheng/NotoSerif/LongCang/ZhiMangXing）
- 宫位阴阳背景色区分
- 设置对话框

### 测试

- 冒烟测试：统宗派年家天目/计神/时计/主客算验证（2020/2024/2026）
- Flutter 测试：金镜派和统宗派年家规则完整验证（天目/计神/时计/主客算/大将/八门/贵神/三气/三基）
- 测试覆盖年份：2004/2005/2020/2024/2026

### 工程

- AI 协同宪法体系（AI_README.md + 12 模块）
- 看板系统（docs/board/）
- 项目文档（PRD/功能说明/ADR/Changelog）
- `example/` 示例项目：独立 Flutter App，通过 path 依赖根包，含 Web 启动脚本（run_web.sh / run_web.bat）
- Git 依赖：package:common（通用术数基础库）

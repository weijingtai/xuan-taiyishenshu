## 流派规则差异

### 金镜派（古法基准）

- 古积年基数：10,155,219
- 纪元：1303 CE
- 太乙宫公式：`(局数 - 1) / 3`
- 文昌：阳遁起申，阴遁起寅，保留重留规则
- 计神：十六神体系
- 八门：随太乙宫起开门
- 章岁/章月：657/8726

### 统宗派

- 古积年基数：10,155,219
- 纪元：1303 CE（与金镜同）
- 太乙宫公式：与金镜同
- 文昌：重留规则简化
- 五福宫：加 250 盈差
- 计神：十六神体系，可配置跳间神
- 八门：随宫与固定两种配置
- 额外星神：青龙旗/黑旗/赤旗、贵神值事（60 年周期）

### 集成派（当代简法）

- 积年起算：1684 CE（当代甲子元）
- 太乙宫公式：`局数 / 3`
- 文昌：取消重留规则
- 计神：十二神体系
- 八门：固定宫位
- 不涉及章岁/章月

## UI 功能

### 示例项目（example/）

- 独立 Flutter App，通过 `path: ..` 依赖根项目 `taiyishenshu` 包
- 入口文件 `example/lib/main.dart`，通过 `package:taiyishenshu` 引用根项目组件
- 启动脚本：`run_web.sh`（Bash）和 `run_web.bat`（Windows），默认端口 7357，支持自定义端口
- 脚本配置了持久化 Chrome profile 和 `--disable-web-security`

### 主页面（TaiYiPanPage）

- 日期时间选择器（日历 + 时间 + "现在"快捷按钮）
- 盘类型选择：年家/月家/日家/时家（ChoiceChips）
- 流派选择：金镜派/统宗派/集成派（ChoiceChips）
- 样式选择：经典/罗盘（ChoiceChips）
- 响应式布局：宽屏并排（网格 + 信息面板），窄屏垂直堆叠
- 设置对话框：日期/时间/流派/盘类型选择
- 错误状态展示

### 排盘网格

| 组件 | 说明 |
|------|------|
| TaiYiPanGrid（经典） | 三层嵌套方形（外圈星神/中圈十六神/内圈洛书九宫），放射线 + 对角线 |
| TaiYiPanGridV2（罗盘） | 圆角矩形 + 圆形，实线对角线 + 虚线中线，现代罗盘风格 |
| NineGongGrid | 标准 3×3 九宫格，每宫展示八卦/地支/八门/星神/阴阳数/主客算 |

### 信息面板（PanInfoPanel）

分区展示：
1. 标题（流派 + 盘类型 + 时间）
2. 基础参数（积年/局数/遁法/太乙宫等）
3. 年计参数（仅年家：五子元局/元数/入纪/年卦等）
4. 主客定算卡片（主算/客算/定算 + 大将/参将落宫）
5. 太乙阴阳数
6. 八门排布
7. 格局列表（含严重度和典籍引用）
8. 地盘信息
9. 人盘信息
10. 天盘信息
11. 神盘信息
12. 贵神排布（九宫网格）
13. 提示/预警
14. 选中宫详情

## 技术实现要点

- **算法入口**：`TaiYiPanCalculator`（1740 行），单一计算器类，内部 `_RuleProfile` 封装流派差异
- **输入模型**：`PanInputModel`（日期/流派/盘类型/真太阳时/地点/出生时间）
- **输出模型**：`PanDataModel`（整合六层盘面 + 格局 + 命盘 + 年计 + 贵神 + 主客算 + 警告）
- **状态管理**：`TaiYiPanController`（ChangeNotifier），手动 Listener 订阅，无第三方库
- **主题系统**：`TaiYiClassicTheme`（16 种命名颜色 + 八卦/地支/层级颜色映射 + 谷歌字体）

## 已知限制

1. 格局判断仅实现 6 种大格局，小格局待补充
2. 自定义神煞框架就绪但评估算法未实现
3. 时家阴阳遁分界依赖节气日，精度受历法库影响
4. 部分传本差异以 `warnings` 标记，未做多版本对照
5. 月家/日家/时家测试覆盖不足
6. 导航路由（navigator.dart）未被使用，为遗留代码

## 发现与修正 (Findings & Fixes)

1. **Engine 偏移错误**: `steppedCycle` 在计算第一年时存在 1 步的偏移，已在 `algorithm_engine.dart` 中修复。
2. **宫位系统不一致**: `nineGong` 系统在 Engine 中包含了中宫，导致落宫偏移，已将其与 canonical `taiYiPalaceOrder` 对齐（跳过中宫）。
3. **资产 ID 与文件名**: 官方 JSON 文件名为 `jing-mirror.json` 但 ID 为 `jingMirror`，Repository 加载时需注意映射（已在 Mock 测试中手动映射）。
4. **全链路集成**: `TaiYiPanController` 现在统一管理官方与用户仓库，支持动态计算模版配置化加载。

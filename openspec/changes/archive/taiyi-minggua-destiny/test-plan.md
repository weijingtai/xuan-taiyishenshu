# Test Plan: taiyi-minggua-destiny

## 1. MingGua（命卦）测试

### 1.1 单元测试：核心算法

| 测试用例 | 输入 | 预期输出 |
|----------|------|----------|
| 标准年份计算 | year=2026, epochBase=10153917 | accYear=10155943, remainder=10155943%64, 对应卦 |
| 余数=0 映射到第64卦 | 使 accYear%64==0 的年份 | guaIndex=64, 卦名=未济 |
| 余数=1 映射到第1卦 | 使 accYear%64==1 的年份 | guaIndex=1, 卦名=乾 |
| 阳辰动爻方向 | GanZhi偶数索引 | 从初爻向上数 |
| 阴辰动爻方向 | GanZhi奇数索引 | 从上爻向下数 |
| 动爻余数=6 | remainder 使 (r-1)%6==5 | 阳辰→position=6; 阴辰→position=1 |
| 变卦翻转正确 | 已知本卦+动爻 | 仅动爻位翻转 |

# Proposal: 太乙命卦 + 太乙人道命法

## Problem Statement

项目已有完整的太乙局法排盘系统（年/月/日/时计），但缺少两个重要的命学分支：
1. **太乙命卦（统运入卦）**：基于积年÷64的卦运体系，用于推演国运/大运/本命基调
2. **太乙人道命法（命盘）**：基于时计局法的个人命盘体系，用于推演六亲/事业/健康

这两个体系在《太乙统宗宝鉴》中有明确的独立篇章，是太乙体系的重要组成部分。

## Proposed Solution

采用**方案 C（混合架构）**：
- 命卦：独立轻量引擎（算法简单，mod 64 + 查表 + 爻变）
- 命法：扩展 rule engine 模式（与现有局法同源，十二宫映射走配置化）

两者共享 Repository/MVVM 架构模式，Contract 统一在 `repository-interface-taiyishenshu`。

## Key Decisions

| 决策 | 选择 | 理由 |
|------|------|------|
| 命卦引擎 | 独立实现 | 算法极简，rule engine 有额外开销 |
| 命法引擎 | 复用 rule engine + taiyi_pan_calculator | 同源体系，复用时计+星神逻辑 |
| 十二宫映射 | JSON 配置化 | 文档明确"无统一标准"，需可编辑 |
| Interface 层 | 扩展现有 package | 保持统一的 Contract 体系 |
| 目录结构 | lib/minggua/ + lib/destiny/ | 互不依赖，独立测试 |

## Scope

### In Scope
- 命卦核心算法 + 配置化
- 命法时计入局 + 星神 + 十二宫映射
- Repository 接口 + 实现
- MVVM + UseCase
- MVP Sample UI
- 单元测试 + 集成测试

### Out of Scope
- 命卦断卦逻辑（卦义解读文本 → 后续迭代）
- 命法流年运势推演
- 高级 UI（可视化盘面、动画）
- 多语言支持

## Risks & Mitigations

| 风险 | 影响 | 缓解 |
|------|------|------|
| 十二宫映射规则无统一标准 | 不同版本产出不同结果 | 配置化 + 多版本共存 |
| 命法复用时计逻辑时发现 bug | 影响现有排盘功能 | 只读调用，不修改现有代码 |
| 动爻阴阳辰计算公式有争议 | 卦象错误 | 严格遵循统宗卷十六，配置化允许切换 |
